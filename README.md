# Calculator

A modern scientific calculator built with **Python** and **Tkinter**.

## Current Version
**v1.2 Alpha**

## Description

Calculator is a desktop scientific calculator featuring a modern dark interface and essential mathematical functions. The project is currently in active development, with new features being added through development snapshots before stable releases.

## Features

### Basic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Decimal Numbers
- Parentheses
- Percentage

### Scientific Functions
- sin()
- cos()
- tan() (Degree Mode)
- log()
- ln()
- Square (x²)
- Power (xʸ)
- Square Root (√)
- Reciprocal (1/x)

### Constants
- π (Pi)
- e (Euler's Number)

### Interface
- Modern Dark Theme
- Scientific Button Layout
- AC (All Clear)
- DEL (Delete Last Character)

## Planned Features

- Memory Functions (MC, MR, M+, M-, MS)
- Calculation History
- Degree / Radian Mode
- Inverse Trigonometric Functions
- Cube & Cube Root
- Factorial
- Keyboard Input
- Settings
- Themes

## Development Workflow

```

```

- Tkinter (Included with Python)
